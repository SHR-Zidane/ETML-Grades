## CDC
Pendant le module DEMOMOT l'année passée, j'ai commencé à développer l'application ETML-Grades. C'est un outil web pour aider les élèves de l'ETML à suivre leurs notes et leurs moyennes.

L'objectif de base à ce moment là était d'apprendre le langage de programmation C pour le plaisir.

Pour le module P_PROD, mon objectif est de reprendre ce projet là où je l'avais arrêté, corriger ce qui ne va pas et ajouter les fonctionnalités manquantes pour avoir une application terminée et fonctionnelle.

### Ce qui est fait
- Ajout de notes
- Calcul des moyennes
- cloture de semestre 
- calcul annuel
- Interface utilisateur

### Objectifs
- Finir le CRUD pour les notes
- Ajouter un moyen d'exporter les notes en json et de pouvoir les importer
- Corriger les potentielles bugs
- Faire des tests
- séparer les notes par année 

### technologies utilisées (pour l'instant)
- MSYS2 (Windows)
- Le langage C
- La bibliothèque GTK3
- Git
- Ninja
- Clang (UCRT64 toolchain)
- Cmake
